MISSION 6 MOIS — Application web installable (PWA)

Contenu:
- index.html : application responsive
- manifest.webmanifest : métadonnées PWA
- sw.js : cache hors ligne

Pour l'utiliser:
1. Dézippe le dossier.
2. Héberge le contenu sur un hébergement HTTPS (par exemple GitHub Pages, Netlify ou autre).
3. Ouvre l'URL sur ton téléphone.
4. Android/Chrome : menu ⋮ > Installer l'application ou Ajouter à l'écran d'accueil.
   iPhone/Safari : bouton Partager > Sur l'écran d'accueil.

Sauvegarde:
- Les données se sauvegardent automatiquement dans le navigateur de cet appareil.
- Dans l'application > Sauvegarde, exporte de temps en temps le JSON.
- Cette version ne synchronise pas automatiquement entre plusieurs appareils.
- Si tu effaces les données du navigateur, la progression locale peut être perdue sans export.
