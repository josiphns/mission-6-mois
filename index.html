Mon budget & la récompense

Le tatouage reste une récompense responsable : aucun crédit et pas de nouvel découvert pour le financer. Les chiffres ci-dessous sont tes saisies, pas une connexion bancaire.

Sauvegarde & données

Les données sont sauvegardées automatiquement sur cet appareil dans le navigateur. Pour une sauvegarde de secours, exporte régulièrement un fichier JSON. La synchronisation entre appareils n'est pas activée dans cette version.

Pour installer cette PWA, héberge les fichiers du ZIP sur un site HTTPS, puis utilise « Ajouter à l'écran d'accueil » dans ton navigateur. Le mode hors ligne est activé après le premier chargement.
